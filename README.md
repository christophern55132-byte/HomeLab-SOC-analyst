# HomeLab SOC Analyst

## Overview

This repository documents my SOC Analyst homelab where Windows security events are generated, investigated, and documented.

## Lab Environment

| Machine | Operating System | Role |
|---------|------------------|------|
| Kali Linux | Kali Linux | Attacker |
| Windows 10 | Windows 10 | Victim |
| Ubuntu | Ubuntu Linux | SOC Analyst |

## Objectives

- Generate security events
- Analyze Windows Event Logs
- Investigate incidents
- Produce professional reports
- Practice SOC Analyst workflows

## Workflow

1. Generate an attack
2. Collect evidence
3. Analyze logs
4. Investigate
5. Create Incident Report
6. Recommend mitigations
